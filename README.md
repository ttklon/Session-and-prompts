# Genspark Arkhivator — архив чатов Genspark в TXT (Windows 11)

Бесплатная программа: вставляете ссылку на чат Genspark → она сама открывает страницу
в вашем Chrome/Edge (без логина, без Playwright), выгружает **весь текст чата**
(ваши промпты, ответы агента, запущенные агенты, инструменты, размышления — всё)
в `.txt` + HTML-снимок, строит описание в 3 режимах и кладёт чат в вечный архив
с поиском, заметками и избранным.

Интерфейс — пиксельная тема «Майнкрафт» (зелёные кирпичные рамки, пергамент,
объёмные кнопки) по эталонному `reference_screenshot.png`, всё рисуется кодом,
без внешних картинок и библиотек.

## Запуск (для пользователя, не программиста)

**Вариант А — готовый EXE (ничего устанавливать не надо, кроме Chrome/Edge):**
скачайте `genspark_arkhivator.exe` из раздела
[Actions](../../actions) → последний успешный запуск «Build Windows EXE» → Artifacts
(или из Releases, если включён релиз). Запустите двойным кликом.

**Вариант Б — из исходников:**
1. Установите Python 3.10+ с https://www.python.org/downloads/ — при установке
   **обязательно** галочка «Add Python to PATH».
2. Установите Chrome или Edge (есть почти у всех).
3. Двойной клик по `run.bat` — он сам поставит библиотеки один раз и запустит программу.

Демо-данные для знакомства: `python gui.py --demo` (или `run.bat --demo`).

## Что умеет

| Возможность | Как работает |
|---|---|
| Выгрузка чата по ссылке | Selenium (Chrome→Edge), Selenium Manager сам качает драйвер. Без Playwright, без логина. Приватный чат — программа честно скажет, что страница пустая |
| Полный текст | Автопрокрутка до дна + автоклик по свёрнутым блокам «размышления/агенты/инструменты/показать ещё» (слова настраиваются в `selectors.json`) |
| TXT навсегда | `data/chats/<дата>_<название>_<id>.txt` + `.html` снимок; ссылки не перепроверяются — выгрузили один раз, лежит вечно |
| Описания в 3 режимах | Офлайн, без ИИ: экстрактивное сжатие (частота слов × позиция × сигнальные слова) — минимум 10–15, среднее 40–50, максимум 70+ предложений |
| Описание через ИИ (опционально) | Бесплатный ключ Gemini с https://aistudio.google.com → поле внизу окна, «Описание: gemini». Нет ключа/сети — автоматический откат на офлайн |
| Умный поиск | Понимает опечатки («селениум брузер с ашибкай»), ищет в названиях, описаниях и полном тексте TXT. Движок RapidFuzz (MIT, GitHub), без него — встроенный запасной |
| Семантический поиск | Кнопка «🧠 Семантика»: TF-IDF + словарь синонимов — понимает «кнопка»=«button», «ошибка»=«баг», даже без общих слов |
| Подсветка совпадений | Жёлтые вхождения в TXT + кнопки «◀ пред. / след. ▶» |
| Систематизация | Сортировка: начало сессии / последнее открытие / название; ★ избранное; огромные заметки (Ctrl+S, автосохранение каждые 1.5 с) |
| Мои промпты | Вкладка: сохранение своих промптов, привязка к чату, двойной клик — поиск похожих чатов по промпту |
| Дубликаты | Правый клик по списку → «Дубликаты и похожие»: md5-сигнатуры + Jaccard по 5-словным шинглам |
| Экспорт | Весь архив в ZIP (кнопка внизу); один чат в Markdown (правый клик) |
| Темы | Майнкрафт (по умолчанию) / Светлая / Тёмная / Кубики — переключаются **без перезапуска** |

## Структура проекта

```
gui.py             — окно и вся логика UI (MC-виджеты)
widgets.py         — пиксельные виджеты: MCFrame/MCButton/MCEntry/MCStatusLight/MCCheckbox/MCTabs
theme.py           — темы; «Майнкрафт» — точная палитра по reference_screenshot.png
extractor.py       — Selenium-выгрузка (без Playwright, без логина)
db.py              — SQLite + data/chats/*.txt,*.html
summarizer.py      — офлайн-описания 12/45/75 предложений + опциональный Gemini
search.py          — fuzzy-поиск с опечатками (RapidFuzz → difflib)
semantic_search.py — TF-IDF + синонимы (офлайн)
duplicates.py      — дубликаты: md5 + Jaccard-шинглы
prompts.py         — «Мои промпты» (SQLite)
selectors.json     — слова-раскрыватели блоков, прокрутка, селекторы — без правки кода
run.bat            — запуск для Windows (сам ставит зависимости)
build/             — PyInstaller .spec и Inno Setup .iss
.github/workflows/ — GitHub Action: сборка готового EXE на windows-latest
reference_screenshot.png — эталон интерфейса
```

## Сборка EXE локально

```
pip install -r requirements.txt pyinstaller
pyinstaller build/genspark_arkhivator.spec
# готовый файл: dist/genspark_arkhivator.exe
```

Или просто запушьте в `main` — GitHub Action соберёт EXE сам и выложит в Artifacts.

## Тонкая настройка без кода

- `selectors.json` → `expander_patterns`: какие подписи свёрнутых блоков раскрывать
  (например, добавить своё слово, если Genspark переименует «размышления»);
- `max_scrolls`, `scroll_pause` — глубина прокрутки для очень длинных чатов;
- `semantic_search.py` → `SYNONYMS` — свой словарь синонимов для семантического поиска.

Всё локально, всё бесплатно, никаких серверов: база и тексты лежат рядом с программой в `data/`.
